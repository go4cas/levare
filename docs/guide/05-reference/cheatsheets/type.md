# Type — `types/<name>.md`

A work-unit template: what a unit of this type is expected to produce, and where it gates.

| Field | Type | Required | Nullable | Enum values | Description |
|---|---|---|---|---|---|
| `name` | string | ✅ | — | — | The work-unit type's name. |
